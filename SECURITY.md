# Security Policy

## Supported versions

The latest released version is supported.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, open a [GitHub security advisory](https://github.com/saromanov/logrus-loki-hook/security/advisories/new) or contact the maintainer directly. Include as much information as possible: affected versions, reproduction steps and impact.

You can expect an initial response within 7 days.
